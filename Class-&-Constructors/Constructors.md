# What is a Constructor?

In CPP, while dealing with member functions and classes, we come across a term called "CONSTRUCTOR". 

Constructor is also a member function of a class but has a special type. 

Constructor is a special type of member function, it's name is same as that of the class. It does not have any return type.

When we create an object, this member function is automatically called. 
   
Its primary purpose is to initialize the object's data members with valid starting values, ensuring the object begins its lifecycle in a safe,
predictable state.

*Think of a constructor like a factory blueprint's setup routine: when a machine is built from the blueprint, the setup routine instantly fills the fuel tank, sets the clock, and boots up the system before anyone ever presses the "Start" button.*  

# Types
Constructors are of three types:

> ### Default Constructor:
It is a type of constructor which doesn't take in any type of argument. 

> ### Parameterized Constructor:
It is a type of constructor which accepts the parameters, to initialize special objects with specific values.
